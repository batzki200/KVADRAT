# КВАДРАТ — сайт отделочной бригады (демо для портфолио)

Одностраничный сайт + страницы услуг для ниши «ремонт и отделка». Сделан на той же
технической базе, что и MICRODOM, но с переработанным дизайном под строительную тему.

**Ниша:** отделка квартир под ключ, ванная, плитка, стяжка, обои.
**Регион:** Минск.

> ⚠️ Это демонстрационный проект. Все контакты (телефон, e-mail, адрес), название бренда,
> отзывы и цифры - вымышленные заглушки. Перед публикацией замените их на реальные данные.

---

## Что внутри

```
KVADRAT/
├── index.html              # Главная: hero, о бригаде, услуги, работы, цены, калькулятор, этапы, отзывы, контакты
├── styles.css              # Стили: тёмно-графитовая тема + охра, шрифты Oswald + PT Sans
├── script.js               # Мобильное меню, валидация формы, отправка заявки
├── estimate.js             # Калькулятор стоимости (select → цена → Telegram)
├── send.php                # Обработчик заявок (почта + fallback в leads/)
├── token.php               # CSRF-токен (double-submit cookie)
├── config.php              # Боевой домен и почта для заявок
├── .htaccess               # HTTPS-редирект, security-заголовки, кэш, сжатие
├── robots.txt
├── sitemap.xml
├── composer.json           # PHPMailer
├── Dockerfile / docker-compose.yml
├── assets/                 # Логотип (SVG), favicon, фото
└── services/               # 5 страниц услуг
```

## Дизайн

- Палитра: тёплый графит `#17150f` + охра `#d9822b` (акцент) + жёлтый `#f2b705`.
- Шрифты: **Oswald** (жирные заголовки, uppercase) и **PT Sans** (текст).
- Hero: слева крупный заголовок в две строки (вторая - акцентная), короткий подзаголовок,
  кнопки и блок цифр; справа - фото бригады в спецодежде на белом фоне, низ фото прижат
  к нижней границе hero (без «парящей» обрезки).
- Адаптив. Только светлая тема.

## Развёртывание

1. Залить файлы в корень хостинга (`public_html` / `www`).
2. Настроить домен (A-запись), включить HTTPS (Let's Encrypt).
3. В `config.php` указать боевой домен и почту для заявок.
4. В `index.html` и страницах `services/` заменить `https://kvadrat.by/` во всех
   SEO-мета-тегах и `canonical` (блок помечен комментариями), а также номер телефона,
   e-mail и Telegram-ник.
5. Проверить: `http://домен/send.php` отвечает JSON (POST-запрос).

Требования хостинга: PHP 7.4+, поддержка `mail()` или SMTP.
`vendor/` (PHPMailer) не обязателен: если его нет, форма работает через встроенный `mail()`,
а при неудаче заявка сохраняется в `leads/` как подстраховка.

### Локальный запуск

```
php -S 0.0.0.0:8000 -t KVADRAT
```

Открыть http://localhost:8000

Или через Docker:

```
docker compose up
```

## Лицензии на фото

Фото бригады в hero (`assets/hero-team.jpg`) и часть фото работ взяты в демонстрационных целях.
Перед публикацией замените их на собственные фото объектов или изображения со свободной
лицензией: Яндекс.Картинки агрегирует чужие (в т.ч. лицензированные) изображения, и
использование их на боевом сайте может нарушать авторские права.

Если у фото бригады белый фон, а фон hero тоже белый - границы не видно. При смене фона
hero на цветной фото придётся вырезать (убрать фон) или дать ему подложку.
